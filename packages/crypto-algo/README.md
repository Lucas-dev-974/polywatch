# @polywatch/crypto-algo

Ce package contient le module d'automatisation et de trading algorithmique de Polywatch.

Pour la documentation complète et détaillée sur l'architecture, le fonctionnement des stratégies, le pipeline d'entrée et le paramétrage, veuillez consulter :

👉 **[docs/crypto-algo.md](../../docs/crypto-algo.md)**

## Développement local

Pour démarrer ce package individuellement pendant le développement :

```bash
npm run dev -w @polywatch/crypto-algo
```

Pour exécuter les tests du package :

```bash
npm test -w @polywatch/crypto-algo
```
